Your lights mirror the busiest agent across every worktree.

Colour legend

Blocked pulsing — an agent is stuck
Waiting breathing — wants your input
Working steady — agent is running
Done steady — finished recently
Idle off — nothing running

Setup

  1. Open the Yeelight app, pick each light, and turn on LAN Control.
  2. Run Yeelight: Discover Lights from the command palette.
  3. Run Yeelight: Test Colour Mapping to walk the palette.

If discovery finds nothing, your network is probably blocking multicast — add each light's IP under devices in the config file instead.

Configuration

Colours, brightness, effects, and manual device IPs live in ~/.orca/yeelight.json. Saving the file reloads it immediately — no restart.
